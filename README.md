# ⚔ Fantasy 2D Arcade — Dungeon Defender

An **original**, dependency-free, fantasy-themed survival arcade game built with HTML5 Canvas, CSS, and JavaScript.

> This is a new implementation prepared for the `fantasy-2d-arcade` repository. It is **not** a verified reproduction of any pre-existing repository source code.

## 🎮 Play

Open `index.html` in any modern browser, or publish the repository using **GitHub Pages**.

- **Move:** WASD or arrow keys
- **Attack:** Space or tap/click in the arena (aims in the clicked direction)
- **Pause:** P, Escape, or the Pause button
- **Restart:** Restart button
- **Mobile:** On-screen direction and attack controls

Defeat enemies, collect dropped crystals, survive increasingly difficult waves, and beat your locally saved high score.

## 🧩 Files

| File | Role |
| --- | --- |
| `index.html` | Page structure and game screen |
| `style.css` | Responsive layout and visual design |
| `game.js` | Gameplay, rendering, input, enemy AI, scoring and collision logic |

## 🚀 Publish on GitHub Pages

1. Upload all files to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, then select `main` and `/(root)` (if appropriate for your repository).
4. Open `https://basiliskouloumpis.github.io/fantasy-2d-arcade/` after deployment.

No build tools or external packages are required.

## 🔧 Extend the game

Add character sprites, sound effects, boss fights, levels, upgrades, or a leaderboard. The game is a single-player browser prototype and does not use a backend.
